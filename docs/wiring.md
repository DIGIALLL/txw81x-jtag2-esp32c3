# Проводка: ESP32-C3 SuperMini ↔ камера TXW817

Интерфейс отладки Taixin TXW81x — двухпроводной C-SKY JTAG2 (CKHAD):

- **HCK** — тактовая линия (от программатора);
- **HDA** — двунаправленная линия данных.

Уровни 3,3 В, у C3 они такие же, преобразователь не нужен. Питание камера берёт от своего
USB/АКБ, с программатором у неё должна быть **общая земля**.

## Чёрная плата `STD-X5-817-V02` (проверено)

| Пад на плате камеры | ESP32-C3 SuperMini | Назначение |
|---|---|---|
| HCK | GPIO7 | такт JTAG2 |
| HDA | GPIO5 | данные JTAG2 |
| DP  | GPIO20 (или GPIO6, `!rx 6`) | лог загрузки (UART TX камеры, 115200 8N1), только вход |
| GND | GND | общая земля |
| RST | — | не нужен: пада не сбрасывает чип |

Протокол работает и на уже запущенной камере: ловить момент загрузки не нужно.

## Синяя круглая плата `IOT_V1.2 D250609` (сенсор SP0828) — связь проверена

На плате подписаны пады **PA9**, **PA10**, **DP**, а также GND и питание.
Проверено: **PA10 = HCK, PA9 = HDA**, DP = UART TX (лог), HID `0x14039322`, флеш 1 МБ `0xCD1460CD`.

Все сигналы идут на площадки GPIO4–GPIO7 программатора (на чёрной плате использовались они же).

| Пад на плате камеры | ESP32-C3 SuperMini | Примечание |
|---|---|---|
| PA9  | GPIO7 | **HDA** |
| PA10 | GPIO5 | **HCK** |
| DP   | GPIO6 | UART TX (лог): `!rx 6` |
| GND  | GND | обязательно |
| —    | GPIO4 | свободна |

Проверка (после открытия порта C3 перезагружается):

```
!jpins 5 7 3
!jinit
!hid                 -> HID=0x14039322
```

Утилита: `python tools/txwprog.py --hck 5 --hda 7 --wdt-off dump blue.bin`.

**Сторожевой таймер.** Родная прошивка синей камеры включает WDT, поэтому через 1–2 секунды после
остановки ядра чип сбрасывается прямо посреди загрузки алгоритма: запись в ОЗУ обрывается
(`wblk … bad=16`), и ядро зависает до перезапуска питания. Флаг `--wdt-off` сразу после остановки
пишет в `WDT_KEY` (0x40015004) `0xAAAA`, затем `0xDDDD`. После этого `WDT_CON` (0x40015000)
меняется с `0x18` на `0x08` (бит 4 = включён).

`!jbrute` (перебор всех пар GPIO4…7) при подключённом DP на GPIO6 лучше не запускать: он по очереди
делает выходами все четыре ноги и на мгновение будет «спорить» с выходом TX камеры.

### Советы по пайке

- Провода МГТФ/«кинар» 30 AWG длиной до 10–15 см. На длинных проводах растут сбои чтения.
- Сначала залудить пады, провод припаивать коротким касанием: пады маленькие и легко отрываются.
- Перед подключением к C3 прозвонить, что соседние пады не замкнуты.
- Провод UART (DP) после прошивки лучше отпаять. Есть подозрение, что шум на линии RX
  камеры однажды загнал её в загрузчик ПЗУ, и флеш оказался стёрт (не доказано).
